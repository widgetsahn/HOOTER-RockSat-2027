Core 0 is solely responsible for keeping time in IDF FreeRTOS.
Therefore, anything that prevents Core 0 from incrementing the tick count, such as suspending the scheduler on Core 0,
will cause the entire scheduler's timekeeping to lag behind.

Users that require the use of the float type in an ISR routine 
should refer to the CONFIG_FREERTOS_FPU_IN_ISR configuration option.
